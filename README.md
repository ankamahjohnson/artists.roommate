# artists.roommate
A place for singers, rappers, beat makers and producers to keep works in progress safe: lyrics, ideas, audio sketches and cover art, with saved versions so nothing gets lost.  

## Live Demo
View Live 🌐
https://ankamahjohnson.github.io/artists.roommate/

## Features

- **Start anything**: New Work opens a picker for Song or lyrics, Beat, Cover art, Idea or Project (EP or album)
- **Lyric sheet** with autosave and live word count
- **Takes**: save a version before a big rewrite and restore it any time
- **Audio sketches**: import a song, loop or voice memo, then play, seek and loop it
- **Cover art**: square preview, full-size view, and a crop tool for images that aren't square (saved up to 3000 x 3000 px)
- **Release info**: the metadata distributors and Spotify ask for, kept beside your audio
  - Track details: ISRC, BPM, key, genre, language, explicit flag
  - Release details: label, dates, UPC, distributor, P and C lines, tracklist for projects
  - Credits with roles and songwriting splits that should total 100%
  - Rights and publishing: ISWC, publisher, rights society, IPI, cover and sample disclosures
  - Pitch and links: moods, instruments, a short pitch, artist profile links
  - A readiness checklist, format warnings that never block you, and one-click copy as plain text
- **Ideas capture**: jot down a stray line without opening a full piece
- **Organise**: types, statuses (Sketch, In progress, Refining, Final take), tags, search, and a trash with restore
- **Export** any piece as a text file
- **Responsive**: sidebar on desktop, slide-in menu and tabs on phones

## Data

Everything is stored in your browser (localStorage and IndexedDB). There is no server or account, so clearing site data deletes your works.

## Browser support

Current Chrome, Edge, Firefox and Safari. MP3, WAV and M4A are the safest audio formats.
