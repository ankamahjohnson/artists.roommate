# artists.roommate
A place for singers, rappers, beat makers and producers to keep works in progress safe: lyrics, ideas, audio sketches and cover art, with saved versions so nothing gets lost.  

## Live Demo
View Live 🌐
https://ankamahjohnson.github.io/artists.roommate/

## Features

- Lyric sheet with autosave and word count
- Takes: save a version before a rewrite and restore it later
- Audio sketches: import a song or loop, then play, seek and loop it
- Cover art: square preview, full-size view and a crop tool
- Quick idea capture, tags, search and trash with restore
- Export any piece as a text file
- Responsive on desktop and mobile

## Data

Everything is stored in your browser (localStorage and IndexedDB). There is no server or account, so clearing site data deletes your works.
